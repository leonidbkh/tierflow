# Tierflow v0.1.8

- Move files with names close to the filesystem limit without ENAMETOOLONG.
  Permission probes and partial/backup paths no longer append unbounded text
  to the original filename; original media names remain unchanged.
- Send the required status-table selector when querying Tdarr queues:
  table1 for transcodes and table4 for health checks. Verified with Tdarr 3.04.00.
- Include the existing main-branch fix making dry-run free of filesystem side
  effects and unnecessary open-file probes.
- Derive the Nix package version from Cargo.toml to keep package metadata and
  the binary version aligned.

Regression coverage includes long ASCII/Cyrillic filenames, preserving an
existing destination as a backup, both Tdarr queue requests, and dry-run safety.
